# v0.62

*Upgrading from*: v0.61.*

## What changed from v0.61.*

Manifest kinds now always have both a `Plural` and a `Resource`. See [Manifest kinds require `Plural` and `Resource`](#manifest-kinds-require-plural-and-resource).

## Manifest kinds require `Plural` and `Resource`

Every `app.ManifestVersionKind` in manifest data now has two required fields:

* `Plural` (`plural` in JSON), the capitalized, human readable plural of the kind, for example `Issues`.
* `Resource` (`resource` in JSON), the all-lowercase plural used as the resource in the k8s GroupVersionResource URL, for example `issues`.
  It must be a valid k8s resource name (a lowercase RFC 1123 label).

When generating a manifest from CUE, the SDK still fills these in for you: `Plural` is the kind's `pluralName` (defaulting to the kind + `s`),
and `Resource` is its lowercase form. A manifest saved as JSON is only valid when both are set, and `ManifestData.Validate()` returns an error otherwise.

What this means for your code:

1. **Hand-written `app.ManifestVersionKind` values** (for example in tests) must set both `Plural` and `Resource`.
2. **`ManifestVersionKind.Resource()` is removed.** It is replaced by the `Resource` field. It used to derive the resource from `Plural` (or from the kind),
   so code that read `Plural` as the resource name must read `Resource` instead.
3. **Custom route registration** in `k8s` now uses `Resource` for URL paths. A `Plural` of `Issues` registers routes under `issues`, as before.
4. **`AppManifest` v1alpha1 and v1alpha2** have a new optional `resource` field on kinds. When it is unset, `Resource` is the lowercase of `plural`
   (or of the kind + `s` if `plural` is also unset), and `Plural` has its first letter capitalized.
5. **Regenerate your manifest** with `grafana-app-sdk generate` so the generated manifest Go code includes `Resource`.

## Migration steps

1. If you build `app.ManifestVersionKind` values by hand, set `Plural` and `Resource`, and replace calls to `Resource()` with the field.
2. Run `grafana-app-sdk generate` to regenerate your manifest.
3. Run `go build ./...` and your tests.
