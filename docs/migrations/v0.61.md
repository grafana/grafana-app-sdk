# v0.61

*Upgrading from*: v0.60.*

## What changed from v0.60.*

`grafana-app-sdk generate` now writes an [RTK Query](https://redux-toolkit.js.org/rtk-query/overview) API for every kind with TypeScript codegen enabled, alongside the existing TypeScript types:

* `<tsGenPath>/<kind>/<version>/<kind>_api_gen.ts` — `use<Verb><Kind>Query`/`Mutation` hooks, in the same shape as the clients core Grafana generates in `@grafana/api-clients`
* `<tsGenPath>/createBaseQuery.gen.ts` — shared base query over `getBackendSrv()`

These files import `@reduxjs/toolkit`, which the frontend plugin must now depend on (and `react-redux` to use the hooks):

```bash
cd plugin && yarn add @reduxjs/toolkit react-redux
```

Projects created with `grafana-app-sdk project init` on v0.61+ get these dependencies automatically. Projects that do not want the generated API can disable TypeScript codegen for the kind with `codegen: ts: enabled: false`, which also stops generating the TypeScript types.
