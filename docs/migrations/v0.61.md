# v0.61

*Upgrading from*: v0.60.*

## What changed from v0.60.*

The `k8s/apiserver` package has been removed, and the SDK no longer depends directly on `k8s.io/apiserver`.

The package contained the default `AppInstaller` used to install apps into a kubernetes-style API server,
along with a standalone, etcd-backed API server runner (`Options`, `Config`, and `cmd/server`).
The standalone runner is gone, with no replacement. The installer code now lives in Grafana as
`github.com/grafana/grafana/pkg/apiserver/appsdk`.

## Migrating

* **`apiserver.ToOpenAPIName`**: use `jennies.ToOpenAPIName` from `github.com/grafana/grafana-app-sdk/codegen/jennies`.
* **`AppInstaller`, `NewDefaultAppInstaller`, `GenericAPIServer`, `StatusREST`, etc.**: import them from
  `github.com/grafana/grafana/pkg/apiserver/appsdk` instead of `github.com/grafana/grafana-app-sdk/k8s/apiserver`.
  The exported API is unchanged. The OpenAPI model names of the package's own types (`ResourceCallOptions`, `EmptyObject`)
  now use the new package path (`com.github.grafana.grafana.pkg.apiserver.appsdk.*`).
* **`apiserver.Options`, `apiserver.Config`, `cmd/server.NewCommandStartServer`**: removed. Run apps with
  `operator.Runner`, or install them into Grafana.
